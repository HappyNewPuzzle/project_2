# 17단계: 프론트엔드 대화 목록 연결

이번 단계의 목표는 16단계에서 만든 대화방 API를 최소 프론트엔드에 연결하는 것입니다.

## 추가·수정한 파일

- [frontend/index.html](../../frontend/index.html)
  - 대화 목록 새로고침 버튼을 추가했습니다.
  - 대화방을 선택하면 `/conversations/{id}/messages`로 메시지를 불러옵니다.
  - 현재 대화 삭제 버튼을 추가했습니다.
  - 스트리밍 완료 후 대화 목록을 자동 새로고침합니다.

- [backend/docs/README.md](README.md)
  - 17단계 문서 링크를 추가했습니다.

- [backend/README.md](../README.md)
  - 현재 단계를 17단계로 갱신했습니다.

## 사용자 흐름

```text
로그인
  → 대화 목록 새로고침
  → 과거 대화 선택
  → 메시지 기록 복원
  → 이어서 스트리밍 채팅
  → 필요하면 현재 대화 삭제
```

## 왜 중요한가?

대화가 DB에 저장되어도 사용자가 다시 열 수 없다면 실제 서비스 경험은 반쪽입니다.
이번 단계로 최소 UI에서도 저장된 대화를 확인하고 이어갈 수 있게 되었습니다.

## 한계

- 대화방 제목은 아직 UUID 그대로 표시합니다.
- 캐릭터 이름을 목록에 함께 보여주지는 않습니다.
- 페이지네이션 UI는 아직 없습니다.

다음 단계에서는 단일 프로세스 메모리 rate limit을 Redis 기반으로 확장할 준비를 합니다.
