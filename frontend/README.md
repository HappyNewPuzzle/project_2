# AI Character Chat Frontend

백엔드 API를 손으로 테스트하기 위한 최소 정적 프론트엔드입니다. 빌드 도구 없이
HTML 파일 하나로 동작합니다.

## 실행 방법

먼저 백엔드를 실행합니다.

```powershell
cd backend
docker compose up --build
```

다른 터미널에서 프론트엔드를 정적 파일 서버로 엽니다.

```powershell
cd frontend
python -m http.server 5173
```

브라우저에서 다음 주소로 접속합니다.

```text
http://127.0.0.1:5173
```

## 사용 순서

1. API Base URL이 `http://127.0.0.1:8000`인지 확인합니다.
2. 회원가입합니다.
3. 로그인합니다.
4. 캐릭터를 생성합니다.
5. 필요하면 기억을 저장합니다.
6. 스트리밍 채팅을 전송합니다.

## 현재 한계

- 개발용 단일 HTML 파일입니다.
- 토큰은 `localStorage`에 저장하므로 운영용 보안 설계가 아닙니다.
- 회원가입 중복, 토큰 만료, 상세 오류 UX는 단순하게 처리합니다.
- 프론트엔드 테스트와 빌드 파이프라인은 아직 없습니다.
